# ShuhariTech Web Portal

The official website, documentation hub, and project directory for **ShuhariTech** and **Fumiko**, hosted via GitHub Pages.

**Visit Live Site:** [https://animeforlife191.github.io](https://animeforlife191.github.io)

---

## What's Here

* **`index.html`** — ShuhariTech home page, project mission, and the *Shu-Ha-Ri (守破離)* philosophy.
* **`fumiko.html`** — Flagship product page for **Fumiko**, a private, local-first email watcher with on-device AI.
* **`docs.html`** — Dynamic documentation viewer powered by `marked.js` and `highlight.js`, fetching live architecture notes directly from the Fumiko repository.
* **`applications.html`** — Application catalog and status roster.
* **`support.html`** — Community feedback, bug reporting, and ways to support development.
* **`privacy.html`** — Privacy policy outlining local-only data processing and credential safety.
* **`assets/`** — Shared CSS stylesheets, color themes, and branding assets.

---

## Local Preview

Because this is a static site with vanilla HTML, CSS, and client-side JavaScript, you can run and preview it locally with any lightweight server:

```bash
# Using Python
python3 -m http.server 8000

# Then open http://localhost:8000 in your browser
```
